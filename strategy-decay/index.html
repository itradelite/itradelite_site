Strategy Decay.

A research and diagnostic investigation, not a signals page: does each of iTradeLite's 7 strategy archetypes (3 original, 4 added in a later pass — see below) have real edge, isolated from the others — and if it ever did, when (and why) did that edge stop being distinguishable from luck?

What this page is (and isn't) This is a statistical audit of historical signal performance, run in isolation per archetype with a random-entry noise-band control — it exists to answer "is there real edge here," honestly, including when the honest answer is no. It is not a live signals feed, not investment advice, and a "no edge ever distinguishable from noise" verdict is reported exactly as plainly as any other outcome. 3 archetypes (Post-Earnings Drift, 52-Week-High Momentum, Gap Fade/Continuation) are newly wired into the live signal pipeline and start with zero historical signals — an "insufficient data" verdict there is expected on early runs, not a bug. A 7th row, Baseline (Random Entry), is a backtest-only control (never a live signal) that formalizes the same random-entry-under-regime-gate check already used to build every other archetype's noise band, as its own directly-comparable result. Educational purpose only. Trading involves significant risk of loss.

Full methodology
Same 5-day stop-first R-multiple engine tools/build_public_metrics.py already publishes, filtered to one archetype at a time — no composite blending. 75-day rolling windows (midpoint of a 60–90 day range), 5-day step, minimum 8 trades per window to score a point. Change-points found via CUSUM (cumulative sum of deviations from the series mean; estimated break = argmax|Ct|) with permutation-test significance (2000 shuffles, α=0.05). The noise band is 200 bootstrap replicates of a random-entry baseline — same symbol, same percentage risk-per-share (same position sizing), a random entry date within ±45 days instead of the strategy's own signal timing — giving a 5th–95th percentile band; a window only counts as real edge if it falls outside that band. Position sizing and transaction costs are identical to the composite: R-multiples are already risk-normalized, and no commission/spread/slippage is modeled anywhere in this pipeline. Source: decay_stats.py / backtest_strategy_decay.py.

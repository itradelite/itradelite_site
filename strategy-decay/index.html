Strategy Decay.

A research and diagnostic investigation, not a signals page: does each of iTradeLite's 3 strategy archetypes have real edge, isolated from the others — and if it ever did, when (and why) did that edge stop being distinguishable from luck?

What this page is (and isn't) This is a statistical audit of historical signal performance, run in isolation per archetype with a random-entry noise-band control — it exists to answer "is there real edge here," honestly, including when the honest answer is no. It is not a live signals feed, not investment advice, and a "no edge ever distinguishable from noise" verdict is reported exactly as plainly as any other outcome. Educational purpose only. Full methodology
Same 5-day stop-first R-multiple engine tools/build_public_metrics.py already publishes, filtered to one archetype at a time — no composite blending. 75-day rolling windows (midpoint of a 60–90 day range), 5-day step, minimum 8 trades per window to score a point. Change-points found via CUSUM (cumulative sum of deviations from the series mean; estimated break = argmax|Ct|) with permutation-test significance (2000 shuffles, α=0.05). The noise band is 200 bootstrap replicates of a random-entry baseline — same symbol, same percentage risk-per-share (same position sizing), a random entry date within ±45 days instead of the strategy's own signal timing — giving a 5th–95th percentile band; a window only counts as real edge if it falls outside that band. Position sizing and transaction costs are identical to the composite: R-multiples are already risk-normalized, and no commission/spread/slippage is modeled anywhere in this pipeline. Source: decay_stats.py / backtest_strategy_decay.py.
